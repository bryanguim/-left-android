# Left — Android

Le temps en points, en noir et blanc, style Liquid Glass.

## Ce qu'il y a dedans
- **Temps** : Jour (live à la seconde), Semaine, Mois, Année, Vie (années ou mois)
- **Décomptes** : tes événements, avec les jours qui s'effacent
- **Réglages** : date de naissance, espérance de vie, points ronds/carrés, widgets Verre/Noir, pulsation
- **6 widgets** : Jour, Semaine, Mois, Année, Vie, Décompte — le point actuel pulse, mise à jour tous les quarts d'heure

## Obtenir l'APK sans rien installer (GitHub)
1. Crée un dépôt sur github.com (ex. `left-android`).
2. « uploading an existing file » → glisse **tout le contenu** de ce dossier (y compris `.github`).
3. Onglet **Actions** : le build se lance tout seul (~5 min).
4. Onglet **Releases** : télécharge `Left.apk` depuis ton téléphone et installe-le.

Chaque nouvelle modif envoyée sur GitHub refait un APK qui s'installe par-dessus l'ancien.

## Avec Android Studio
Ouvrir ce dossier → **Build › Build App Bundle(s) / APK(s) › Build APK(s)**.
